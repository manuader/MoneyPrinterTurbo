# Tanda de terror liminal / turno noche. Ficción, personajes compuestos.
#
# Por qué este tema, y no otro:
#
# 1. TRACCIÓN. El terror liminal — lugares familiares pero vacíos — es la
#    corriente con más interés ahora mismo, empujada por el estreno de
#    Backrooms en mayo de 2026. Las historias de turno noche vienen creciendo
#    en el mismo envión.
#
# 2. NICHO PROBADO. La narración de historias inquietantes es el formato
#    faceless con mejor rendimiento sostenido. No necesita cara ni cámara.
#
# 3. Y LA RAZÓN OPERATIVA: el material de stock para lugares vacíos es
#    abundante y de buena calidad. Oficinas de noche, estacionamientos,
#    escaleras, pasillos con fluorescentes. Es exactamente lo contrario del
#    problema que tuvimos con fraudes bancarios y rescates en interiores.
#    El tema con más tracción resulta ser también el más fácil de ilustrar.
#
# Cada variación usa un mecanismo de giro distinto: imposibilidad
# arquitectónica, repetición, un objeto que no cierra, una llamada que no
# puede existir, y algo que llevaba años quieto y se movió.
